# Orbit

A private expense tracker for iPhone, built as a web app you add to your Home Screen.

Open it on your iPhone: **https://suyash-2004.github.io/orbit/**

In Safari, tap ••• then Share, then **Add to Home Screen**, and keep "Open as Web App" on.

## Editing

The app source lives in `src/`. After changing it, run `python3 build.py` to rebuild `index.html` and the icons (needs `rsvg-convert`), then commit.

All data is stored on the phone (localStorage). Use Settings → Back up data to save a copy.
